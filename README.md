## 🚀 Getting Started & Compilation

To compile and run any of the C programs in this repository, ensure you have a C compiler installed (such as `gcc`). Open your terminal and run the following commands:

```bash
# Clone the repository
git clone git@github.com:cyanoge1-netizen/cse-structured-programming-assignment.git

# Navigate into the directory
cd cse-structured-programming-assignment

# Compile a program
gcc prime_checker.c -o prime_checker

# Run the compiled executable
./prime_checker
```
